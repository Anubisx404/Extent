# Security Policy

## Supported Versions

Security updates and patches are actively provided for the following release line:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Extent seriously. If you discover a security vulnerability, please report it responsibly and privately.

### Reporting Channels

1. **GitHub Security Advisories**: If available on this repository, please submit a report privately through the repository's **Security** tab under **Report a vulnerability**.
2. **Repository Maintainer Contact**: If private advisory reporting is unavailable, reach out directly to the repository owner via their GitHub profile contact options.

Please do not open public issues, discussions, or pull requests for undisclosed security vulnerabilities.

### Information to Include

To help us understand and resolve the issue quickly, please include the following details in your report:

- A clear description of the vulnerability.
- Affected Extent version(s) and runtime environment (OS, Go version, Docker version if relevant).
- Step-by-step instructions, proof-of-concept code, or minimal target project to reproduce the issue.
- Potential impact and attack scenarios.
- Any suggested remediations or workarounds, if known.

## Response Goals

We aim to handle vulnerability reports with the following targets:

- **Initial Acknowledgment**: We aim to acknowledge receipt of your report within 48 to 72 hours.
- **Triage & Assessment**: We aim to confirm the issue and provide an initial assessment within 5 business days.
- **Fix & Disclosure**: We work toward preparing and releasing a fix alongside a coordinated disclosure notice as soon as reasonably practicable.

These response timelines represent operational goals rather than binding contractual guarantees.

## Public Disclosure

Please coordinate with maintainers before disclosing any vulnerability details publicly to ensure adequate time for a patch to be prepared and released.
